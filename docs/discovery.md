# 営業候補を自動発掘（最大100社）

## できることと、まだ検証できていないこと

AI企業リサーチに「企業名から検索」「営業候補を自動発掘」の2タブを用意しました。既存のgBizINFO API v2検索は維持しています。新機能は、利用者が取り込んだCSVを母集団として、会社名の事前入力なしで条件一致企業を最大100社抽出します。取得していない企業を生成するコードや、サンプルへ自動切替するコードはありません。

**公式CSV現物の形式・実データでの100社抽出は未検証です。** 2026年10月20日の確認では、このクラウドからgBizINFOのダウンロード案内へのHTTPS接続がプロキシのCONNECT段階で403となり、最新のファイル仕様を直接取得できませんでした。そのため特定の公式ファイルを「完全自動認識できる」とは扱っていません。自動ダウンロードは実装せず、ファイルの列を確認・指定するCSV方式を採用しています。

サポートするのは先頭行が列名の表形式CSVです。現物がこの形式であれば、列対応を指定して取り込めます。JSON/XML/ZIP等や複数段のヘッダー、先頭に説明行がある形式はそのままでは扱えません。公式にCSVが提供されていない場合や形式が異なる場合は、原本仕様に基づく変換処理が別途必要で、今回完成した機能には含めません。

公式案内の起点：https://content.info.gbiz.go.jp/ （ダウンロードの案内へ進み、提供形式・利用条件を確認してください。具体的な最新ボタン名は未確認です。）

## Windowsで最新版を起動

起動しているターミナルでCtrl+Cを押し、package.jsonのあるプロジェクトフォルダーで次を実行します。

```powershell
git switch feature/dswitch-sales-ai
git pull --ff-only origin feature/dswitch-sales-ai
npm.cmd ci
npm.cmd run dev -- --hostname 127.0.0.1
```

ZIPで取得している場合はGitHubのfeature/dswitch-sales-aiブランチ → Code → Download ZIPから再取得し、旧フォルダーを残して別フォルダーへ展開します。新しいフォルダーにも、ご自身の.env.localを安全に配置してください。そのフォルダーでターミナルを開き、npm.cmd ci、npm.cmd run dev -- --hostname 127.0.0.1を実行します。

CSVの取り込み・発掘・一括登録にはAPIトークンは不要です。任意のAPI補完には.env.localのGBIZINFO_API_TOKENが必要です。キーを変えた場合はサーバーを再起動します。キーをGitHub・チャット・CSVに入れないでください。

以前と同じブラウザー・アドレスで開き、Ctrl+F5で再読み込みします。既存の営業データを残すため、サイトデータを削除しないでください。

## CSVを取り込む

1. gBizINFO公式サイトでダウンロード案内・提供仕様・利用条件を確認し、利用可能なデータを取得します。公開ページと原本を照合してください。このアプリではファイルが公式に発行されたこと自体を認証できないため、出所は「利用者指定」と明示します。
2. ZIPはWindowsの「すべて展開」で解凍します。CSV以外の形式や巨大ファイルは、この機能が対応する形式・サイズへ原本仕様に従って変換・分割する必要があります。巨大な全国ファイルの自動分割機能は未実装です。
3. 「AI企業リサーチ」→「営業候補を自動発掘」を開きます。
4. 文字コード（UTF-8／Shift_JIS）を選び、CSVを選択します。原本と異なる文字コードではエラーになる場合があります。取り込み後に文字化けした会社名を事実として使わないでください。
5. 出典ページURLを入力します。content.info.gbiz.go.jp / info.gbiz.go.jp / help.info.gbiz.go.jpの公開HTTPSページのみを受け付けます。トークン・認証情報・クエリ文字列付きURLは入力しないでください。
6. 法人番号・企業名・所在地・業種・従業員数・公式サイト・事業概要の列を、原本の説明を見て対応させます。自動候補は一般的な列名の候補であり、公式仕様を確認済みという意味ではありません。
7. 「列対応を確認して取り込む」を押します。処理行数と結果が表示されます。追加のCSVも同じ方法で取り込めます。

### 対応する入力

- 1ファイル：空でない20MiB以下、50,000データ行まで
- 全取込データ：法人番号で重複排除後50,000社まで
- 先頭行に重複・空欄のない2〜200列の列名。列名は200文字以内
- UTF-8／Shift_JIS。ブラウザー内Workerで全体の文字コードを復号し、その後CSVをチャンク解析。マルチバイト文字のバイト境界で誤分割しない方式
- 法人番号：13桁の文字列、企業名：1〜200文字。これは形式確認であり、登記上の実在・チェックディジット・最新性の確認ではない
- 従業員数：0以上の整数。引用符内の1,000のような3桁区切りも対応。空欄・不明・未取得・ハイフンは不明として保持。50人、約100、負数、小数、指数表記などは推測変換せず不明扱い
- サイト：認証情報なしのhttp(s) URL。安全でない値は未取得扱い
- 業種：取得表記を保持。文字列配列のJSON表記も受け付け、コードを推測変換しない
- 任意項目の上限：従業員数の原表記32文字、サイト2,048文字、所在地2,000文字、業種5,000文字、事業概要10,000文字。超過した任意項目は切り詰めず未取得扱いにして件数を報告

法人番号・企業名が不正な行は除外件数を表示します。不正な任意項目は未取得件数として表示します。引用符・列数・文字コードなどCSV構造にエラーがある場合、ファイル全体の取り込みを中止し、以前に読み込んだデータを保持します。サイズ・行数上限超過でも既存データを初期化しません。

全社情報を含む数百MB〜GBの原本を直接開く機能ではありません。Excelの行数上限を超えるファイルも、完全に読み込めるとは扱わないでください。提供元に分割データがなければ、必要な変換・分割は別作業になります。

## 発掘条件と評価

初期設定は全国（取込範囲内）、デスクワーク関連候補5分類、従業員50〜500名、100社です。地域・業種候補・人数帯・目標10/30/50/100社を変更できます。

業種候補は公式のコード翻訳ではなく、取得した日本語業種名・事業概要の語句一致です。企業名から業種を推測しません。IT・ソフトウェア、広告・マーケティング、コンサルティング、人材サービス、Web制作の語句を確認し、その他は取得情報がある中で該当語がない候補です。名称だけで職場環境を確認済みとはしません。判定は営業向けの仮説です。

住所から都道府県を表示する場合は、取得住所の先頭に都道府県名があるものだけを使います。住所がない／形式を確認できない場合に所在地を生成しません。全国条件では地域の絞り込みはしません。

人数・業種の情報が不明な企業は、指定条件に一致すると見なさず条件判定保留にします。他の既知条件で明確に不一致なら条件不一致です。例えば人数5名と判明していれば、業種がなくても50〜500名の条件には不一致です。人数が不明だから従業員0名とは扱いません。

スコアは [既存の100点ルール](research-sales-scoring.md) を再利用します。営業適性A/B/Cと、情報充実度（主要5項目の充実度点が15点→高、9〜12点→中、6点以下→低）を別に表示します。業種・人数・サイト・所在地・事業概要の未確認項目と収録差異も表示します。情報がないための低得点は不適合ではありません。デスクワーク比率、出社率、福利厚生導入状況は未確認のままです。

## 件数の意味

- 取得済み企業数：今回取り込んだCSV／API補完の範囲の重複排除後の社数
- 条件一致：既知の取得情報で全条件に一致した社数（既存登録企業を除外後）。100社を超える場合もある
- 抽出結果：一致企業をスコア順に並べた上位最大目標件数。同点は法人番号順
- A/B/C：抽出結果だけの件数
- 情報不足・判定保留：条件未確認社数＋条件一致だが欠損や収録差異のある評価要確認社数。後者は条件一致にも含まれるため、全カウンターは単純に合算しない
- 条件不一致と登録済み除外も別表示

取得範囲は取り込んだファイルだけであり、全国の総企業数ではありません。100社に届かない場合は、取得範囲、条件一致・保留・不一致・登録済み除外の件数から不足理由を表示します。名称・所在地しか含まない原本では、人数帯や業種が不明のため多数が保留となり、100社抽出できない場合があります。その場合も企業を生成・水増ししません。

件数は発掘実行時点のスナップショットです。登録後はもう一度発掘すると登録済みの除外が更新されます。

## 任意のAPI補完

「不足情報をAPIで補完」を明示的に実行した場合だけ外部通信します。取込順で不足情報のあるCSV由来企業を1回最大10社取り、法人番号を1社ずつAPI v2詳細へ送ります。対象選定は発掘条件の適用前です。CSV全体・既存営業リスト・履歴・下書きを送信しません。

- 1社1リクエスト、応答後600ms以上あけて次へ。1リクエストのタイムアウト15秒
- 1回最大10社。進捗を表示し、中止可能
- サーバープロセス内で1件ずつ、30回/分・200回/UTC日の上限
- プロセス再起動・開発時の再読み込みでカウンターはリセットされる。公開サービスの恒久的な課金・悪用防止策の代替ではない
- 401/403/429等のエラーは理由を表示してその回の処理を停止。自動リトライしない。利用規約・サービス側の制限は公式の最新案内を確認する
- 成功分は保持。トークンの修正・再起動後にCSVを再取り込みする必要がある場合がある

新しい非欠損値を優先して統合し、APIが返さない値はCSVから保持します。異なる値は差異として両方の取得値・出典を保存し、要確認とします。差異履歴は直近10件までです。異なる法人番号を混ぜません。既にAPIで補完した企業は同じ読み込み状態では再度の補完対象にしません。実行後は発掘を再実行してください。

## 一括登録・CSV出力

結果から複数選択または全選択して登録できます。最大100社で、全件を準備してから保存します。既存の営業データ・履歴・下書きは上書き・削除せず、新規レコードだけを追加します。法人番号で重複排除し、番号のない旧企業は同名も保守的に除外します。同じ法人を繰り返し登録しません。

ブラウザーの保存容量が不足する等で一括登録できない場合は、既存の保存データを残し、一括登録を中止してCSV保存を案内します。容量を空けるためにサイトデータを削除する操作は推奨しません。

CSVは抽出結果（最大100社、未登録・登録済み表示を含む抽出時点の結果）を出力します。選択した企業だけの出力ではありません。企業名／法人番号／都道府県／所在地／業種／従業員数／サイト／スコア／ランク／情報充実度／判定状況／未確認項目／評価理由／取得元／日時／項目別の取得元を含みます。UTF-8 BOM付き、数式対策・改行等のエスケープあり。トークンは含みません。

CSVの取得日時は本アプリへの取込日時です。原本の作成日・更新日ではありません。API補完フィールドの取得日時は実際のAPI取得日時です。項目別の出典・ファイル名・日時をCSVにも記載します。

このCSVは発掘結果の確認用です。従来の営業リスト用CSVインポートとは列構成が異なります。営業リストへの追加は登録ボタンを利用してください。履歴・下書きの完全なバックアップではありません。

## 保持期間と安全性

取込データはブラウザー内Workerのメモリーにのみ保持し、ページ再読み込み・タブ切り替え・画面離脱で破棄されます。必要な結果をCSVまたは営業リストへ保存してください。リサーチ内のタブ切り替えでは破棄前に確認を表示します。サイドメニューで離れる場合も一時データは保持されません。既存営業リストのlocalStorageキーは維持しています。

原本の公開元・利用条件・出典表示・第三者権利を確認したファイルだけを使用してください。出典URLやファイル内容にトークンを含めないでください。形式の検証は出所の真正性を証明するものではありません。Windowsでは127.0.0.1に限定して起動し、認証なしで公開しないでください。

## 検証の区別

- 架空のテスト専用CSV：150社から100社、10/30/50/100の目標、人数帯、保留、重複、列・値・URL検証、上限、CSV、登録前の全件準備を自動テスト
- 実ブラウザー＋架空CSV＋模擬API：Workerで読み込み、100社抽出・CSV出力・100社一括登録・旧履歴と下書きの保持・再抽出時の登録済み除外・追加CSV・1社補完・スマートフォン・従来タブを確認
- 公式CSV現物・実在企業100社の抽出・ご本人のAPIトークン：この環境では未検証。実データの検証完了とは扱わない

実データ検証は、Windowsで原本の列と数行を公式情報と照合してから取り込み、件数・スコア理由・出典・不明項目を確認するところから始めてください。形式が合わない場合は、秘密情報や企業の非公開情報を含めず、公式の項目定義資料とヘッダーを共有すれば原本形式専用のアダプターを追加できます。
