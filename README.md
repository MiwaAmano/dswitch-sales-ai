# d switch Sales AI

株式会社tenの法人向け福利厚生サービス「d switch」の営業管理プロトタイプです。すべて架空の企業データで動作し、メール送信・有料API・自動営業は行いません。

## 起動方法

Node.js 22以上とnpmを用意し、このフォルダーで次を実行します。

```sh
npm ci
npm run dev
```

開発サーバーはポート3000で起動します。クラウド環境ではサービスのポート転送機能がある場合、3000番を指定して表示してください。本番相当で確認する場合は `npm run build` の後に `npm start` を実行します。

## できること

- ダッシュボード：登録企業数、送信・返信・商談・契約企業数、成約率、直近7日間の最終連絡状況、ステータス別グラフ、最近の履歴
- 営業リスト：11項目の登録・編集、削除、検索、ステータス・優先度での絞り込み。企業名を押すと詳細・履歴を表示
- CSV：表示中の企業をUTF-8 BOM付きで出力、CSVから一括追加。エクスポートのヘッダーを雛形に使用。日付はYYYY-MM-DD。2MBまで、同名企業も別レコードとして追加。履歴・下書きはCSVに含みません
- AI企業リサーチ：エリア・業種・人数・キーワードで架空企業を検索、未登録企業を営業リストに追加。同名の登録済み企業は追加不可
- AI営業メール：企業ごとのテンプレート生成、本文・件名の編集、下書き保存、コピー。保存時に未接触をメール作成済へ変更
- 営業進捗：8つのステータスで管理。変更を履歴に保存
- フォローアップ：期限超過・3日以内・未返信・すべての予定を確認、予定日編集、フォローメール生成
- 履歴：企業詳細でメモを記録（最終連絡日を当日に更新）

送信・返信等の数値は現在のステータスに基づく企業数です。送信回数の集計ではありません。送信済は手動で記録します。成約率は契約企業数÷送信済み以降の企業数です。

## データの扱い

データはブラウザーのlocalStorage（`dswitch-sales-v1`）に保存します。端末・ブラウザー間の共有やログイン機能はありません。初回のみサンプル12社を登録します。サイトデータを消すと保存内容は消えます。CSVで定期的にバックアップしてください。読み取り失敗時には元データを上書きしません。

顧客情報のサーバー送信や公開機能はありませんが、この試作品には認証・権限管理・暗号化保管がないため実在の顧客情報は入力しないでください。公式サイトのリンクは例示用のexample.comです。外部フォント・外部画像は使用していません。

```sh

```

CSVの往復、CSVエラー、数式注入対策、メール生成、検索条件のテストがあります。

## 構成と今後の拡張

- `app/page.tsx`：レスポンシブな営業管理画面
- `app/globals.css`：Tailwind CSS 4と共通スタイル
- `lib/sales.ts`：型定義、サンプルデータ、CSV、メールテンプレート、ResearchProvider
- `tests/sales.test.ts`：共通処理の自動テスト

外部検索は `ResearchProvider` の実装をサーバー側APIアダプターに差し替えて拡張できます。Zapier・Gmail連携は将来サーバー側ルートにOAuthと送信承認を追加し、履歴保存と連携する想定です。APIキーはブラウザーへ渡さずサーバー側の環境変数で管理します。受注・発送・商品管理は企業IDを関連キーとした別ドメインとして追加してください。現時点でこれらの連携機能は未実装です。

本運用前にはサーバーDB、認証、アクセス権限、監査ログ、バックアップ、プライバシー管理を追加してください。

## GitHubへの反映

このフォルダーで次を実行します。初回はGitHub側への書き込み権限が必要です。

```sh
git switch -c feature/dswitch-sales-ai
git add .
git commit -m "Build d switch Sales AI prototype"
git push -u origin feature/dswitch-sales-ai
```

GitHubの画面で表示される「Compare & pull request」からmain向けのプルリクエストを作成します。依存関係やビルド出力、秘密情報は.gitignoreで除外します。

## ロゴとWindowsでの更新

公式ロゴは、GitHubへアップロードされた元画像を加工せず `public/dswitch-logo.png` に配置しています。縦横比を保って縮小し、白背景の下にグレーの「Sales AI」を表示します。ファビコンは同じ画像を白い正方形のSVG内に比率を保って配置しています。元画像は199×280pxのため、拡大せず使用しています。

WindowsでGitを使っている場合は、起動中のターミナルでCtrl+Cを押し、プロジェクトフォルダーで次を実行してください。ローカルでファイルを変更している場合は、その変更を先に保存し、強制上書きやリセットはしないでください。

```powershell
git switch feature/dswitch-sales-ai
git pull --ff-only origin feature/dswitch-sales-ai
npm.cmd ci
npm.cmd run dev -- --hostname 127.0.0.1
```

ZIPで取得した場合は、GitHubで `feature/dswitch-sales-ai` ブランチを開き、Code → Download ZIPから再ダウンロードしてください。既存フォルダーは残して別の場所へ展開し、package.jsonがあるフォルダーで「ターミナルで開く」を選び、`npm.cmd ci`、`npm.cmd run dev -- --hostname 127.0.0.1` を順に実行します。以前のサーバーはCtrl+Cで停止してから起動してください。

ブラウザーは同じ端末・同じブラウザー・同じアドレスで開き、Ctrl+F5で再読み込みしてください。保存済み営業データを保つためサイトデータは削除しないでください。念のため更新前のCSVエクスポートも利用できます（CSVには履歴・下書きは含まれません）。ファビコンが古い場合はタブを閉じて開き直してください。
